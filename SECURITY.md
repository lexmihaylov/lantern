# Security policy

Use Lantern only on networks and devices you own or are explicitly authorized to monitor. Its optional ARP interception feature changes peer ARP caches and may disrupt connectivity; use it only with explicit authorization and stop it when the task is complete. Restoration packets are best-effort and do not prove that peer caches were updated.

## Reporting a vulnerability

Please do not disclose vulnerabilities, packet captures, credentials, device inventories, or private network details in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use the **Report a vulnerability** option on its Security tab. Otherwise, contact the maintainers privately through a verified contact method listed on the repository profile. Include affected versions, impact, and reproduction steps while avoiding other users' data.
